# ChatGPT Privacy Blur

A small Chrome extension that blurs:

- ChatGPT's generated replies
- Your sent prompts
- Text in the prompt composer

Hover over a message or the composer to reveal it. Click the extension toolbar
button to turn the effect on or off. Your choice is saved between browser
sessions.

## Install locally

1. Open `chrome://extensions` in Chrome.
2. Turn on **Developer mode** in the top-right corner.
3. Click **Load unpacked**.
4. Select this `hide-chatgpt` folder.
5. Open or refresh [ChatGPT](https://chatgpt.com/).

The toolbar badge says **ON** while privacy blur is active and **OFF** when it
is disabled. If the extension icon is hidden, pin it from Chrome's Extensions
menu.
